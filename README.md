# MCItemStockMarket — 物品股市模组

> 在 Minecraft 中模拟炒股！股票以游戏物品为基础，拥有实时波动的股价、K线图、委托下单、退市/重新上市、跟风股等完整机制。

- **支持版本**：Minecraft 1.21.10（NeoForge 21.10.64+，Java 21）
- **模组版本**：1.0.0
- **语言**：简体中文 / English（随游戏语言自动切换）
- **作者**：VanZ-Y

---

## 特性总览

- 🎮 **按 `K` 键打开股市主界面**：搜索、排序、可拖拽滚动条、退市股自动排末尾
- 📈 **完整行情系统**：分时 K 线、日线、月线三种图表周期
- 💹 **真实的交易机制**：买卖委托、涨跌停板、玩家交易影响价格
- 🔄 **退市与重新上市**：跌破保护价退市并补偿持股玩家，随后可重新上市；跟风股退市后直接删除，不再回归
- 🚀 **跟风股（ST / 指数）**：波动放大、10 分钟内最多触发 3 次、不支持兑换、退市即删除
- 💱 **物品兑换**：货币与游戏物品按股价互相兑换（含 0.8 倍折价规则）
- 💾 **独立 JSON 存档**：股票数据与玩家账户分开存放，安全可靠

## 安装方法

1. 安装对应版本的 [NeoForge](https://projects.neoforged.net/neoforged/neoforge)
2. 将 `mcitemstockmarket-1.0.0.jar` 放入 `.minecraft/mods/` 文件夹
3. 启动游戏，进入任意世界（单人/联机均可，需客户端与服务端同时安装）

## 快速上手

1. 进入世界后，按 **`K`** 键打开股市主界面
2. 在列表中点击任意股票进入详情页，查看实时行情与图表
3. 在详情页输入数量，点击 **买入 / 卖出** 下单
4. 点击 **兑入物品 / 兑出货币** 进行货币与物品互换
5. 点击 **我的持仓** 查看持仓市值与浮动盈亏

> 首次启动时会根据约 95 种物品（矿物、原木、作物、食物、工具、怪物掉落等）随机生成 **50 只初始股票**，发行价为保护价的 1.5 倍；**每种物品的普通股票最多 3 只**。

## 时间体系

模组使用独立的股市时间轴（**1 游戏小时 = 50 秒现实时间**）：

| 事件 | 现实间隔 | 说明 |
|---|---|---|
| 价格随机波动 | 50 秒（1 游戏时） | 分时噪声在 **±0.3%** 内平滑延续（上次噪声×0.7 + 随机×0.3），走势顺滑 |
| 趋势调整 | 20 分钟（1 游戏天） | 全市场在 **±3%** 内平滑延续（昨日趋势×0.6 + 随机×0.4），无断崖跳变 |
| 单日涨跌停 | 24 分钟（1 个交易日） | 单只股票单日波动不得超过 ±10%，触板后禁止继续买入/卖出 |
| 每日播报 | 24 分钟 | 系统广播当日涨幅榜 / 跌幅榜 |

分时噪声幅度远小于日线趋势，属于短期杂波，不会盖过主线方向。

玩家的大额交易也会影响股价：累计交易量达到阈值时，股价按方向小幅移动（默认每次 ±0.05%）。

## 交易指令

所有指令前缀为 `/stocks`，股票名需使用完整名称（如 `村民-钻石股`）。

| 指令 | 说明 |
|---|---|
| `/stocks list [itemId]` | 查看全部股票列表（可点击查询详情） |
| `/stocks portfolio` | 查看我的持仓、待成交委托 |
| `/stocks buy <数量> <股票>` | 提交买入委托（1 ~ 100000） |
| `/stocks sell <数量> <股票>` | 提交卖出委托（1 ~ 100000） |
| `/stocks cancel` | 取消我的全部待成交委托 |
| `/stocks exchange buy <数量> <股票>` | 货币兑换为物品 |
| `/stocks exchange sell <数量> <股票>` | 物品兑换为货币 |
| `/stocks price <股票>` | 查询单只股票详情 |
| `/stocks trend <itemId>` | 查询某物品当前趋势值与玩家影响值 |

### 兑换规则

- **货币 → 物品**：按当前股价兑换；股票当日 **跌停时禁止**兑入
- **物品 → 货币**：按当前股价的 **0.8 倍** 兑换；涨跌均可
- **跟风股票**：不支持任何形式的兑换

## 玩法机制

### 股票命名
股票名 = `[生物前缀] + [物品名] + 股 + [后缀]`，例如 **村民-钻石股**、**苦力怕-金锭股 ST**。前缀取自游戏内生物名，后缀标记跟风属性，随游戏语言显示。

### 普通股票
- 每隔 5 ~ 10 分钟可能随机上市一只新股：随机挑选有保护价、且该物品下普通股少于 3 只的物品，以该物品现有股票均价发行
- 价格跌破**保护价**即退市，持股玩家按保护价获得货币补偿
- 退市后约 8 ~ 10 分钟重新上市，发行价 = 存活同类均价的 0.8 倍与初始价取高者；若该物品普通股已达 3 只上限，则直接删除不再上市

### 跟风股票（ST / 指数）
- 当日涨幅领先的股票有概率生成跟风股，波动幅度放大（默认数倍）
- 无保护价：价格跌至 0 即崩盘退市，持股玩家无补偿
- 跟风事件 10 分钟内最多触发 3 次
- **退市后不再重新上市，直接删除**

### 账户系统
- 新玩家初始余额 **1000 硬币**（可配置）
- 货币为浮点数，界面显示保留两位小数
- 所有交易采用委托制，成交后即时到账；价格、余额、持仓均精确存储

## 存档与数据

数据保存在世界目录下的独立文件夹（**不会**随世界容量膨胀）：

```
<世界目录>/stockmarket/
├── market.json    # 股票、价格历史、趋势、委托、跟风事件等
└── players.json   # 所有玩家的账户、持仓、余额
```

- 价格调整后立即增量保存，服务器关闭时强制写盘
- 文件为 JSON 格式，可直接查看、备份或迁移

---

## 配置

在游戏内 Mod 配置界面（或 `config/mcitemstockmarket-common.toml`）可调整全部参数，包括但不限于：

- 货币名称、初始余额
- 波动幅度、趋势调整幅度与间隔、涨跌停限制
- 保护价 / 初始价表（支持为每种物品单独设置）
- 股票前缀池、跟风股倍数与触发条件
- 历史数据保留时长、交易影响阈值
